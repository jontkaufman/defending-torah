# Notes — 08 fulfill-greek

## Hook (on-screen, 0–1.5s)

> "'Fulfill' doesn't mean 'abolish' in Greek."

## Receipt (4–25s key beat)

`pleroo` (fulfill) vs `kataluo` (abolish) — Jesus uses both in one verse.

## Source material

- [[matthew-5-17-19-foundation]] — `Torah/wiki/analyses/matthew-5-17-19-foundation.md`

## CTA target

`/articles/matthew-5-17-19-foundation`

## Key claims

- `kataluo` = "destroy / abolish / dissolve".
- `pleroo` = "fill up / complete the meaning of".
- If `pleroo` meant "end", v.17 would be self-contradictory ("I did not come to abolish but to abolish").

## Counter-arguments to expect

"Fulfilled means it's done" → then `kataluo` would be redundant in the same verse.
